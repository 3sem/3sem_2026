# Лабораторная работа №4: Параллельный расчет интеграла методом Монте-Карло

Исследование прироста производительности при использовании многопоточности (POSIX Threads) для вычисления определенного интеграла функции \(f(x) = x^2\) на отрезке \([0, 1]\).

Аналитическое значение интеграла: \(0.333333\).

## Архитектура решения

Взаимодействие разделено на две программы:
1. **`progA`**: Принимает на вход общее число точек (\(N\)) и число потоков (\(n\)). Запускает \(n\) потоков, каждый из которых генерирует \(N/n\) случайных точек в квадрате \([0, 1] \times [0, 1]\). Результаты (доли попаданий под кривую) записываются в **независимые ячейки** разделяемой памяти (System V SHM). 
2. **`progB`**: Подключается к той же разделяемой памяти, собирает результаты из независимых ячеек, суммирует их и вычисляет среднее значение (итоговый интеграл).

Благодаря использованию независимых ячеек (`results[MAX_THREADS]`), **синхронизация (мьютексы) не требуется**. Это позволяет избежать блокировок и очередей потоков, обеспечивая максимальную производительность.
