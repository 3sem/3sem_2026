Задача 1. Эмулятор терминала

Программа shell.c циклически читает команды из стандартного ввода.
Каждая команда запускается в дочернем процессе через fork и execvp,
поэтому программы можно указывать по имени из PATH или полному пути.
После завершения программа получает код возврата через waitpid
и выводит его в stderr. Также обрабатывается завершение по сигналу.

Команды, разделённые символом |, соединяются каналами pipe через dup2.
Все процессы конвейера запускаются до ожидания их завершения.
Ненужные дескрипторы сразу закрываются: у родителя одновременно открыто
не больше трёх дополнительных дескрипторов каналов.
Строка и массивы аргументов выделяются динамически.

Сборка и запуск из папки с исходником:
cc -std=c11 -Wall -Wextra -Wpedantic -O2 shell.c -o shell
./shell

Примеры команд внутри программы:
ls -l
/bin/echo Hello
env | grep HOSTNAME | wc
printf hello | wc -c
false

Для printf hello | wc -c результат равен 5.
Для false выводится код завершения 1. Выход — Ctrl+D на пустой строке.
Разбор аргументов выполняется по пробелам: кавычки, перенаправления
и встроенные команды cd/exit не реализованы.
Проверено на macOS; используются системные вызовы POSIX.
