# Duplex Pipe

Реализация дуплексного канала межпроцессного взаимодействия между `parent` и `child` на основе двух неименованных каналов `pipe`.

## Описание

Для организации двусторонней передачи данных используются два `pipe`:

- `parent_to_child` — передача данных от родительского процесса к дочернему;
- `child_to_parent` — передача данных от дочернего процесса к родительскому.

Структура `Channel` инкапсулирует файловые дескрипторы и операции работы с каналом. Взаимодействие с каналом выполняется через таблицу указателей на функции `ChannelOps`, что позволяет использовать элементы ООП-стиля в C.
