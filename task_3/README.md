# Передача файла тремя способами IPC

Три пары программ переносят файл между двумя процессами и печатают время передачи:

- `shm_sender` / `shm_receiver` - разделяемая память SysV
- `mq_sender` / `mq_receiver` - очередь сообщений SysV
- `fifo_sender` / `fifo_receiver` - именованный канал (FIFO)

## Сборка

cd task_3
make

Программы появятся в каталоге `bin/`. Очистка: `make clean`.

## Запуск

Сначала получатель, потом отправитель. Размер буфера в байтах у обоих должен быть одинаковый. Для проверки удобны 8192, 65536 и 1048576.

```bash
# терминал 1
./bin/shm_receiver out.bin 65536

# терминал 2
./bin/shm_sender in.bin 65536
```

Очередь и канал запускаются так же: `mq_receiver` / `mq_sender` или `fifo_receiver` / `fifo_sender`.

Когда файл передан, получатель печатает число байт и время в секундах.

## Проверка

```bash
md5sum in.bin out.bin
```

Суммы должны совпасть.

Все девять комбинаций (3 способа и 3 размера буфера) на файле 256 МиБ, с проверкой `md5sum` и диаграммами:

```bash
make bench
```

Результаты лежат в `report.md` и в каталоге `report/`. Быстрый прогон на файле 8 МиБ: `make smoke`.
